Auto-Capture Config

Engine

Status: running

After stopping, taps below should no longer be captured (check console logs).

Redact Text

Redacts captured text in the target subtree. The second argument toggles it.

While redacted, the button’s target_text and the field’s placeholder are both sent as ****.

Ignore Interactions

Drops auto-capture for everything inside the target subtree. The second argument toggles it.

Nested ignore — closest wins

Applies ignore(true) to the outer panel and ignore(false) to the inner one. Button 1 goes quiet; Button 2 keeps firing.

outer → ignore(true)

inner → ignore(false)

Tap both buttons and watch SDK Callbacks — only Button 2 produces an event.

Nested redact — closest wins

Applies redact(true) to the outer panel and redact(false) to the inner one. Both buttons still fire; only Button 1’s text is masked.

outer → redact(true)

inner → redact(false)

Compare target_text in SDK Callbacks: **** for Button 1, Visible Label for Button 2.

Declarative attributes

No JS needed — data-userpilot-ignore="false" carves an exception out of an ignored subtree. Active as soon as the screen loads.

data-userpilot-ignore

data-userpilot-ignore="false"
